Requerimientos de Hardware

Para desplegar una aplicación web es necesario disponer de una infraestructura física que soporte el rendimiento, acceso simultáneo y disponibilidad del sistema. Entre los principales componentes se encuentran:

  • Servidor físico o virtual: Capaz de ejecutar servicios web, bases de datos y procesos de backend.
  • Procesador: Mínimo 4 núcleos, recomendado 8 o más para alto tráfico.
  • Memoria RAM: 8 GB mínimo; recomendado 16 GB para aplicaciones de producción.
  • Almacenamiento: SSD para mayor velocidad de lectura/escritura.
  • Fuente de alimentación y sistema de refrigeración: Garantizan disponibilidad y estabilidad.

Requerimientos de Software

El sistema operativo debe corresponder con las necesidades del servidor y de la plataforma seleccionada. Los más comunes son:

  • Linux (Ubuntu Server, CentOS, Debian): Alta estabilidad, seguridad, ideal para servidores.
  • Windows Server: Usado cuando se requiere compatibilidad con tecnologías .NET.

Además, se requieren:

  • Servidor web: Apache, Nginx o IIS.
  • Entorno de ejecución: Node.js, PHP, Python, Java, según la tecnología del proyecto.
  • SGBD: MySQL, PostgreSQL, SQL Server, MongoDB.
  • Herramientas de despliegue: Docker, Git, CI/CD, contenedores o máquinas virtuales.

Conceptos de Redes y Tipos de IP

Para el despliegue de la aplicación se requiere conocer elementos clave de networking:

  • IP Privada: Direcciones usadas para la comunicación interna dentro de una red local.
  • IP Pública: Direcciones accesibles desde internet. Necesaria para publicar una aplicación.
  • IPv4: Formato tradicional (ej. 192.168.0.1).
  • IPv6: Nueva versión con mayor capacidad de direcciones.
  • DNS: Convierte nombres de dominio en direcciones IP.
  • Firewall y seguridad: Controla acceso y protege el servidor.

Dos Grandes Familias de Protocolos

En la transmisión y recepción de datos existen dos familias principales de protocolos:

  • Protocolos TCP/IP: Garantizan una comunicación confiable, verificada y ordenada.
  • Protocolos UDP: Envío rápido sin verificación, usado para streaming y juegos online.

Organizaciones encargadas de estándares:

  • IEEE: Define estándares de redes como Ethernet y WiFi.
  • IETF: Define protocolos de internet (TCP/IP, HTTP, etc.).
  • ISO: Estructuras como el modelo OSI.

Medios de Transmisión

Los datos se transmiten mediante medios guiados y no guiados:

Guiados

  • Par trenzado (Ethernet)
  • Fibra óptica
  • Coaxial

No guiados

  • Radiofrecuencia
  • Microondas
  • Infrarrojo
